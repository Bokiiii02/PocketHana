> 鸿蒙端 Hana Agent控制端应用：将Hana Agent前端特性与鸿蒙系统适配，实现边缘悬浮球、扫码连接、系统级推送 / 分享 / 拖拽等系统原生功能。

## 功能特性

**基础体验**
- **沉浸式全屏**：完美的全屏体验，和其他app使用感受一致
- **跨机型适配**：手机和平板皆页面兼容
- **右缘悬浮球菜单**：点击即可轻松设置，闲置时自动退缩为白条吸附屏幕边缘
- **扫码连接**：扫桌面端二维码自动识别地址；地址变化（换 PC）自动清 Cookie 提示重新验证
- **登录态检测**：有会话 Cookie 视为已登录，打开软件即可直接进入对话界面
- **注入修正**：隐藏移动端前端页面无用按钮、隐藏滚动条、侧边栏避让、输入框自适应等（官方页面为桌面端设计）
- **修复前端能力**支持卡片消息显示（原版不支持），对话展开栏按钮加入会话完成提醒标识，展开后标识显示完成的会话

**手机系统能力集成**
- **系统分享到对话**：任意 App 分享图片（单张/多张，上限 10）→ PocketHana 自动填入对话输入框附件
- **中转站拖拽**：中转站拖图片/文字进对话，图片进附件、文字自动填入输入框
- **图片交互**：消息图片支持系统级保存（保存框选路径）、长按菜单（复制图片到剪贴板 / 系统分享面板）、下载按钮保存

**未来能力规划**
- **推送提醒**：app可以后台推送会话完成消息，桌面显示角标提示完成的会话数（已测试可行，等未来如果上架即可加入）
- **清单进度提醒**通过系统实况窗显示agent实时清单完成进度（在测试，计划未来上架加入）

## 首次使用

1. 打开 App，填入你的 Hanako 服务器地址
2. 页面内输入桌面端生成的**访问密钥**登录
3. 登录后会话之后免登录（只要你不是重装软件QwQ）

## 适配机制说明

软件通过在 `onPageEnd` 后注入 CSS/JS 修正官方页面在手机上的表现：

- CSS：横栏避让、侧边栏 padding、滚动条隐藏、弹层防超界、字号 rem 化
- JS：隐藏工作台多余选项、会话列表元信息精简、状态栏高度内联修正、拖拽注入、图片下载/长按拦截
- 注入类名依赖官方构建产物哈希，官方页面升级后可能需要更新

## 注意事项

- 默认服务器地址为空，首次打开会引导设置地址（设置菜单或扫码连接）
- 仅限局域网使用；公网访问需自行配置内网穿透
- 注入样式依赖官方页面的类名结构，随官方版本更新可能失效，需同步维护
- 非图片文件附件受官方前端限制（文件附件机制为服务器路径引用），手机本地文件暂不支持
