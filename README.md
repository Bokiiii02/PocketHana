# Hanako Mobile（鸿蒙壳）

> 鸿蒙端 Hanako 个人助手壳应用：ArkWeb 封装官方移动端页面，沉浸式适配、边缘白条菜单、扫码连接、跨机型排版修正

把 HanaAgent（Hanako AI 助手）的官方移动端页面打包成鸿蒙 App 的轻量壳。保留官方页面 100% 的交互与视觉，壳层补齐原生体验：沉浸式全屏、跨机型适配、边缘菜单、扫码连接、登录态检测。

## 功能特性

- **沉浸式全屏**：系统栏透明，状态栏区域与页面一体；顶部横栏实测状态栏高度避让，按钮可点
- **跨机型适配**：状态栏高度实测注入、屏宽/高度自适应、`--titlebar-h` 变量覆写（浏览器卡/toast/侧边栏同步偏移）、横竖屏切换重算、字号跟随系统缩放
- **右缘白条菜单**：点击展开居中设置面板（淡入缩放动画），内含服务器地址、扫码连接
- **扫码连接**：扫桌面端二维码自动识别地址；地址变化（换 PC）自动清 Cookie 提示重新验证
- **登录态检测**：有会话 Cookie 视为已登录，未登录（登录页）自动隐藏白条
- **注入修正**：隐藏工作台多余选项、隐藏滚动条、侧边栏避让、输入框自适应等（官方页面为桌面端设计，移动端需覆盖）
- **连接兜底**：服务器不可达时暖纸色错误页，可重试/改地址

## 构建与运行

1. 用 DevEco Studio（API 24+）打开本目录
2. 首次打开自动配置签名，连接真机点 Run
3. 命令行：`devecocli build` / `devecocli run`

构建产物：`entry/build/default/outputs/default/`

## 首次使用

1. 打开 App，在设置菜单（右缘白条）或错误页修改服务器地址为你的 Hanako 服务器
2. 页面内输入桌面端生成的**访问密钥**登录
3. 登录后会话 Cookie 持久化，之后免登录

## 适配机制说明

壳通过在 `onPageEnd` 后注入 CSS/JS 修正官方页面在手机上的表现（见 `Index.ets` 的 `injectUiFixes`）：

- CSS：横栏避让、侧边栏 padding、滚动条隐藏、弹层防超界、字号 rem 化
- JS：隐藏工作台多余选项、会话列表元信息精简、状态栏高度内联修正
- 注入类名依赖官方构建产物哈希，官方页面升级后可能需要更新

## 注意事项

- 默认服务器地址为空，首次打开会引导设置地址（设置菜单或扫码连接）
- 仅限局域网使用；公网访问需自行配置内网穿透
- 注入样式依赖官方页面的类名结构，随官方版本更新可能失效，需同步维护
